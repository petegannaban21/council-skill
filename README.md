# council-skill

Five independent perspectives (contrarian, first-principles, expansionist, outsider, executor) plus a chairman synthesis. Run before a consequential or hard-to-reverse decision. No dependencies.

## Install

In Claude Code:

```
/plugin marketplace add petegannaban21/council-skill
/plugin install council@council-skill
```

## Manual install (no marketplace)

```
cp -r skills/council ~/.claude/skills/council
```
